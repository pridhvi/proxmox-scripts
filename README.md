# Proxmox Scripts

Self-contained installers for Proxmox VE LXC containers.

## Scripts

- [OpenClaw LXC](openclaw/README.md): Creates an unprivileged Debian 13 AMD64 container and installs OpenClaw.
- [LiteLLM LXC](litellm/README.md): Creates a LiteLLM gateway with PostgreSQL in an unprivileged Debian 13 AMD64 container.
